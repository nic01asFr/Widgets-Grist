Mode local (hors Grist) — vous pouvez analyser un fichier et voir la preview des couches. L’import dans Grist (création des tables, SceneManifest, carte live) nécessite d’ouvrir ce widget dans un document Grist (Custom Widget). Utilisez Chrome et glissez-déposez le fichier si le bouton ne répond pas.
Déposer un fichier QGIS
Glissez-déposez un export qgis2web ou un projet QGIS. Le widget analyse les couches, crée le schéma de tables Grist et peuple les données.
