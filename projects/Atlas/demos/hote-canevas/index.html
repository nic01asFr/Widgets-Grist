Hôte de démonstration : le canevas d'Atlas dans une application externe

L'application complète d'Atlas (relief, 3D, interface) dans une page, pilotée par la page. Les données de cette page sont synthétiques. Ce que la page envoie : une scène Atlas ; ce qu'elle reçoit : ce que la personne vise et clique.

Liaison

État : connexion…

Une scène Atlas

La scène est envoyée par setScene (Scene Manifest 0.2.2). Cliquez ou survolez un point : la page reçoit select et hover.

Une maquette en dalles 3D

Une couche type: "dalles3d" désigne la maquette par l'adresse de son manifeste de grille. Le serveur doit être en https (ou localhost) et autoriser l'origine de cette page.
